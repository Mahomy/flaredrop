# FlareDrop ☁️🔥

> High-performance Cloudflare Image Vault, Hosting & Instant CDN URL Generator.

Upload single or batch images, generate instant direct CDN URLs, filter and search through your cards, and copy URLs with one click.

## Features
- **Batch Upload:** Drag & drop PNG, JPG, WEBP, GIF, SVG.
- **Card-Based UI:** Shows preview, file size, dimensions, format, and instant clickable URL.
- **1-Click Copy:** Click any URL pill to copy directly to clipboard.
- **Search & Filter:** Real-time search by filename, format pill filters, and sorting.
- **Cloudflare Images Integration:** Optional Cloudflare API integration for native global edge delivery.
- **Local Vault Fallback:** Works 100% offline out-of-the-box with browser storage if no Cloudflare keys are entered.
- **Zero-Error Cloudflare Pages Ready:** Pre-configured with `.npmrc` legacy-peer-deps, SPA redirects, and Vite build.
